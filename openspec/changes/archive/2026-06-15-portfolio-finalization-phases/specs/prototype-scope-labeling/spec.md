## ADDED Requirements

### Requirement: Inventory Prototype 표기
시스템과 문서는 Inventory를 완료 기능이 아닌 `Prototype`으로 표시해야 한다(MUST).

#### Scenario: 포트폴리오 범위 확인
- **WHEN** 리뷰어가 README 또는 Inventory UI를 확인한다
- **THEN** Inventory가 저장 및 완성된 경제 시스템이 아닌 프로토타입임을 확인할 수 있다

### Requirement: Quest Prototype 표기
시스템과 문서는 Quest를 완료 기능이 아닌 `Prototype`으로 표시해야 한다(MUST).

#### Scenario: 포트폴리오 범위 확인
- **WHEN** 리뷰어가 README 또는 Quest 관련 문서를 확인한다
- **THEN** Quest가 핵심 1v1 완료 기능에 포함되지 않는 프로토타입임을 확인할 수 있다
