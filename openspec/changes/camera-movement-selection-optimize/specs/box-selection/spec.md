## ADDED Requirements

### Requirement: 좌클릭 드래그 박스 선택
시스템은 좌클릭 드래그로 화면상의 유닛을 선택할 수 있어야 한다(MUST).

#### Scenario: 박스 선택
- **WHEN** 플레이어가 좌클릭으로 드래그하여 상자를 만든다
- **THEN** 상자 안에 중심점이 있는 유닛만 선택된다

#### Scenario: 빈 공간 클릭
- **WHEN** 플레이어가 빈 공간을 좌클릭한다
- **THEN** 선택된 유닛이 모두 해제된다

### Requirement: 단일 유닛 클릭 선택
시스템은 좌클릭으로 개별 유닛을 선택할 수 있어야 한다(MUST).

#### Scenario: 유닛 클릭
- **WHEN** 플레이어가 유닛을 좌클릭한다
- **THEN** 해당 유닛만 선택된다

#### Scenario: 시프트 클릭 추가 선택
- **WHEN** 플레이어가 Shift를 누른 상태로 유닛을 좌클릭한다
- **THEN** 기존 선택에 유닛이 추가된다

### Requirement: 선택 시각 피드백
시스템은 선택된 유닛을 시각적으로 표시해야 한다(MUST).

#### Scenario: 유닛 선택 시
- **WHEN** 유닛이 선택된다
- **THEN** 유닛이 선택 색상으로 변경된다
