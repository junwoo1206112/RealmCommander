# 테스트 케이스 문서
## Realm Commander

이 문서는 현재 완료 범위인 서버 권한형 RTS 1v1 수직 슬라이스의 수동/자동 검증 기준이다. RPG 확장 기능, 별도 스킬 UI, Inventory, Quest 테스트는 현재 범위에서 제외한다.

## 자동 smoke 필수 확인

| ID | 항목 | 기대 결과 |
|---|---|---|
| SMK-001 | Windows Development Build | `[PortfolioBuild] PASS` |
| SMK-002 | Host 시작 | TCP `7777` listen |
| SMK-003 | Client 접속 | Host에 연결되고 team 1 배정 |
| SMK-004 | 팀/소유권 | `team 0/1`과 소유 유닛 분리 |
| SMK-005 | 자원 격리 | `RESOURCE_ISOLATION_PASS` |
| SMK-006 | Host 이동 | `HOST_MOVE_PASS` |
| SMK-007 | Client 이동 왕복 | `CLIENT_PASS`와 `HOST_PASS` |

## 수동 테스트

### TC-001: 단일 유닛 선택

| 항목 | 내용 |
|---|---|
| 전제조건 | 게임 시작, 플레이어 유닛 1개 이상 존재 |
| 절차 | 유닛 위에서 좌클릭 |
| 기대 결과 | 유닛이 선택되고 선택 표시가 활성화된다 |
| 우선순위 | P0 |

### TC-002: 박스 선택

| 항목 | 내용 |
|---|---|
| 전제조건 | 플레이어 유닛 3개 이상 존재 |
| 절차 | 빈 공간에서 드래그 후 유닛을 포함해 종료 |
| 기대 결과 | 박스 안의 소유 유닛이 선택된다 |
| 우선순위 | P0 |

### TC-003: 이동 명령

| 항목 | 내용 |
|---|---|
| 전제조건 | 소유 유닛 선택 |
| 절차 | 빈 지형에 우클릭 |
| 기대 결과 | 서버가 목적지를 보정하고 유닛 이동을 동기화한다 |
| 우선순위 | P0 |

### TC-004: 공격 명령

| 항목 | 내용 |
|---|---|
| 전제조건 | 소유 유닛 선택, 적 유닛 존재 |
| 절차 | 적 유닛 우클릭 |
| 기대 결과 | 유닛이 접근 후 공격하고 HP가 감소한다 |
| 우선순위 | P0 |

### TC-005: 비소유 명령 차단

| 항목 | 내용 |
|---|---|
| 전제조건 | Host와 Client가 서로 다른 팀으로 접속 |
| 절차 | 상대 팀 유닛을 선택/명령하려고 시도 |
| 기대 결과 | 명령이 실행되지 않는다 |
| 우선순위 | P0 |

### TC-006: 자원 표시

| 항목 | 내용 |
|---|---|
| 전제조건 | ResourceManager 존재 |
| 절차 | 생산 또는 자원 생성 후 HUD 확인 |
| 기대 결과 | 로컬 팀 Gold/Mana만 표시된다 |
| 우선순위 | P1 |

### TC-007: 생산 큐

| 항목 | 내용 |
|---|---|
| 전제조건 | 생산 가능한 건물 선택 |
| 절차 | 유닛 생산 명령 |
| 기대 결과 | 비용이 차감되고 생산 완료 후 유닛이 생성된다 |
| 우선순위 | P1 |

### TC-008: 승패 결과

| 항목 | 내용 |
|---|---|
| 전제조건 | 한 팀의 전투 가능 유닛/건물이 모두 제거됨 |
| 절차 | 승패 판정 대기 |
| 기대 결과 | GameResultUI가 승리/패배를 표시한다 |
| 우선순위 | P1 |

## 제외 테스트

- RPG 확장 기능
- 별도 스킬 UI
- RPG 레벨업
- Inventory
- Quest

## 결과 기록 규칙

PASS로 표기하려면 실행 날짜, Unity 버전, 빌드 종류, Host/Client 실행 명령, 로그 파일 경로를 함께 남긴다.
