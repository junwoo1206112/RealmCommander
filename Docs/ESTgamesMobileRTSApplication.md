## 프로젝트 포지셔닝

Realm Commander는 여러 장르 기능을 나열하는 프로젝트가 아니라 다음 문장으로 소개한다.

> Unity 6와 C#으로 제작한 모바일 RTS 클라이언트 수직 슬라이스. 터치 기반 부대 선택과 명령, NavMesh 이동, UGUI HUD, CSV 밸런스 데이터, Mirror 서버 권한 검증을 구현했다.

## README와 면접에서 설명할 문제 해결

### 터치 입력 충돌

Unity의 레거시 입력은 모바일 터치를 마우스 입력으로도 해석할 수 있다. 기존 `BoxSelector`와 `CommandInput`을 모바일에서 중지하고 `MobileRTSInput`만 입력을 소비하도록 분리했다.

### 네트워크 권한

클라이언트가 모든 유닛의 전투 갱신을 실행하지 않도록 서버 시뮬레이션으로 제한하고, 비소유 유닛 선택과 명령을 차단했다.

### 모바일 데이터 로딩

빌드에서 보장되지 않는 `Application.dataPath` 파일 접근을 제거하고 `Resources.Load<TextAsset>` 기반으로 전환했다.
