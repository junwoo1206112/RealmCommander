# 게임 디자인 문서 (GDD)
## 영웅의 전장 (Realm Commander)

---

## 1. 게임 개요

### 1.1 게임 컨셉
RTS(Real-Time Strategy)와 RPG(Role-Playing Game)를 결합한 하이브리드 모바일 게임. 
플레이어는 유닛을 생산하고 건물을 관리하는 RTS 요소와, 영웅을 육성하고 장비를 관리하는 RPG 요소를 동시에 즐긴다.

### 1.2 타겟 플랫폼
- 모바일 (Android, iOS)
- PC (선택적)

### 1.3 핵심 재미
1. **전략적 전투**: 유닉 조합과 포지셔닝으로 적을 제압
2. **영웅 성장**: 레벨업, 스킬 해금, 장비 파밍
3. **실시간 대전**: 다른 플레이어와의 1v1 대전

## 2. 게임 시스템

### 2.1 RTS 시스템

#### 2.1.1 유닛 선택
- **좌클릭**: 단일 유닛 선택
- **드래그**: 박스 선택 (범위 내 유닛 일괄 선택)
- **Shift + 클릭**: 선택 추가/제거
- **Ctrl + A**: 전체 유닛 선택

#### 2.1.2 유닛 명령
- **우클릭 (빈 공간)**: 이동
- **우클릭 (적 유닛)**: 공격
- **A 키**: 공격 이동 (이동 중 적 발견 시 자동 공격)
- **S 키**: 정지
- **H 키**: 홀드 포지션 (제자리에서 공격)

#### 2.1.3 리소스 시스템
| 리소스 | 용도 | 생성 방식 |
|--------|------|-----------|
| 골드 | 유닛 생산, 건물 건설 | 자원 건물, 맵 자원 |
| 마나 | 영웅 스킬, 특수 능력 | 자연 회복, 자원 건물 |

#### 2.1.4 건물 시스템
| 건물 | 기능 | 비용 |
|------|------|------|
| 본부 | 유닛 생산 제한, 마나 생성 | - |
| 병영 | 근접 유닛 생산 | 200 골드 |
| 사격장 | 원거리 유닛 생산 | 250 골드 |
| 마법탑 | 마법 유닛 생산 | 300 골드 |
| 자원소 | 골드 자동 생성 | 150 골드 |

### 2.2 RPG 시스템

> **참고:** 현재 구현된 RPG 범위는 Commander Hero 1기와 스킬 2개(Arc Strike, Rally Heal)까지만 완료 기능입니다.
> Inventory와 Quest는 Prototype 상태이며 저장, 드롭, 상점 경제와 연결되지 않았습니다.

#### 2.2.1 영웅 시스템 (완료 범위)
- **Commander Hero**: 팀당 1기 자동 생성
- **레벨**: 1~50 (경험치로 레벨업)
- **스탯**: HP, MP, 공격력, 이동속도
- **스킬**: Arc Strike (타겟 데미지), Rally Heal (자가 회복)

#### 2.2.2 스킬 시스템
| 스킬 | 타입 | 설명 |
|------|------|------|
| Arc Strike | 타겟 데미지 | 사거리 내 적 대상 서버 권한 피해 55 |
| Rally Heal | 자가 회복 | 서버 권한 자가 회복 70 |

#### 2.2.3 장비 시스템 (미구현)
| 슬롯 | 효과 |
|------|------|
| 무기 | 공격력 증가 |
| 방어구 | 방어력, HP 증가 |
| 장신구 | 특수 효과 (크리티컬, 회피 등) |

#### 2.2.4 퀘스트 시스템 (Prototype)
- **메인 퀘스트**: 스토리 진행 (미구현)
- **일일 퀘스트**: 매일 반복, 보상 좋음 (미구현)
- **업적 퀘스트**: 특정 조건 달성 (미구현)

## 4. 기술 설계

### 4.1 아키텍처 패턴
- **Singleton Pattern**: GameManager, ResourceManager, SelectionManager 등
- **Observer Pattern**: 이벤트 시스템 (OnHealthChanged, OnSelectionChanged 등)
- **Component Pattern**: Unit, Hero, Building 등 독립적 컴포넌트

### 4.2 네트워킹 (Mirror)
- **NetworkManager**: 게임 방 생성/참가
- **NetworkIdentity**: 유닛, 영웅 동기화
- **ClientRpc/ServerRpc**: 명령 동기화

### 4.3 데이터 관리
- **ScriptableObject**: 유닛 스탯, 스킬 데이터, 아이템 데이터
- **JSON**: 세이브/로드
